# Financial News Analysis Project

## Overview
This project analyzes financial news data to extract insights about market trends, publisher behavior, and content patterns.

## Project Structure
├── .vscode/ # VS Code settings
├── .github/ # GitHub Actions workflows
├── src/ # Source code
├── notebooks/ # Jupyter notebooks for EDA
├── tests/ # Unit tests
└── scripts/ # Utility scripts

## Setup
1. Clone the repository
2. Create virtual environment: `python -m venv venv`
3. Activate environment: `source venv/bin/activate` (Linux/Mac) or `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`

## Usage
- Run EDA: `jupyter notebook notebooks/exploratory_analysis.ipynb`
- Run tests: `pytest tests/`
